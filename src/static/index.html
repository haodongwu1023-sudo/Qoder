三步接入线上会议
第 1 步：安装会议驱动（或 BlackHole / VB-Cable）
• macOS：点击上方「一键安装自研虚拟声卡」安装 VoiceCloneAudioDriver.driver，或使用 BlackHole 2ch
• Windows：安装 VB-Cable（CABLE Input / CABLE Output）
第 2 步：在本软件切换为「会议双向同传」场景
• 在首页将使用场景切换为「会议双向同传」，或前往「音频设备」指定 VoiceClone Mic（输出）与 VoiceClone Meeting Audio（来向）。
第 3 步：在 Zoom / 腾讯会议 / 飞书 / WhatsApp 中选中虚拟设备
• 在通话/会议软件内的音频设置或通话工具栏菜单中设置（不要改动 macOS 系统默认声音，系统默认继续保持你的耳机或 Mac 麦）：
• ① 麦克风选择 VoiceClone Mic（或 BlackHole 2ch）
• ② 扬声器选择 VoiceClone Meeting Audio
